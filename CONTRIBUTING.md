# Contributing to Aether-Guard

First off, thank you for taking the time to contribute! 🎉 Aether-Guard is a community-driven, sovereign mesh project.

## How Can You Contribute?

1. **Reporting Bugs**: Open an issue detailing the bug, steps to reproduce, and your environment (Termux version, Android device, Rust version).
2. **Suggesting Enhancements**: Propose features or security improvements via GitHub Issues.
3. **Pull Requests**:
   - Fork the repo and create your branch from `main`.
   - Ensure your code compiles cleanly (`cargo build`).
   - Test your changes locally across nodes.
   - Submit a Pull Request with a clear description of your changes.

## Code of Conduct
Be respectful, collaborative, and keep security and privacy at the forefront of your contributions.
